EVOSST Energy Index

An integrated energy index for household electricity-consumption behaviour

Project website

Project overview

EVOSST Energy Index develops and validates an integrated measure of household electricity-consumption behaviour. The project combines multiple assessment criteria to classify consumers and support practical recommendations for more efficient electricity use, with experimental validation in a laboratory prototype.

My role & contribution

  • Direct research and project implementation at POLITEHNICA Bucharest.
  • Oversee the energy-index methodology and its experimental validation.

Project context

  • Project code: PN-IV-P8-8.1-PRE-HE-ORG-2025-0290.
  • Funding programme: PNCDI IV, Programme 5.8 European and International Cooperation, Subprogramme 5.8.1 Horizon Europe; Horizon Europe Institutional Awards.
  • Coordinator and sole participant: POLITEHNICA Bucharest.
  • Implementation team: Bogdan-Adrian Enache and George Călin Serițan.
  • Annual budget: 25,125 RON in 2025; 54,250 RON in 2026; 25,125 RON in 2027.
  • First phase, October–December 2025: literature review, initial index architecture and quantitative assessment criteria.
  • Planned dissemination: an international conference paper and an article in a Web of Science-indexed journal.
