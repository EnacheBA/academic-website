CORDIS project recordArchived project website

Project overview

INTERRFACE developed an Interoperable pan-European Grid Services Architecture (IEGSA) connecting transmission system operators (TSOs), distribution system operators (DSOs) and consumers. The project addressed coordinated procurement of balancing, congestion-management and ancillary services, enabling distributed renewable generation, storage and demand response to participate more effectively in electricity markets.

Project context

  • Coordinator: European Dynamics Luxembourg SA, Luxembourg.
  • Digital tools combined big-data management and blockchain technologies to support consumer participation and the use of distributed energy resources.
  • Politehnica University of Bucharest participated in the consortium, with an EU contribution of €450,000.
